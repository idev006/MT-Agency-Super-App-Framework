## 2. End-to-end runtime flow

```
Vue page/store (frontend/src)
  → infrastructure/api adapter  (envelope {apiVersion,group,action,payload,requestId,sessionToken?})
  → Cloudflare Worker  tools/p6vc-api-test-console/worker.mjs
       • Origin lock (https://idev006.github.io)
       • FRONTEND_PAYLOAD_FIELDS allowlist (intentional SUBSET of all ops)
       • public ops must NOT carry sessionToken; requestId format check
  → GAS Web App /exec  (published version)
       ENTRYPOINTS$WebApp → COMPOSITION$Container.createApplication()
       → API$routes$Router.createApiRouter
            • system.health → SystemGroup (public)
            • else → createProtectedDispatcher = OperationController
       → OperationController.dispatch
            1 validateApiRequest (RequestValidator)
            2 route allowlist (GroupRoutes) + handler exists
            3 validateOperationPayload (OperationPayloadValidator DTO_SCHEMAS)
            4 sessions.authorize(sessionToken, OPERATION_PERMISSIONS[op])  ← server-authoritative RBAC
            5 handlers[op] invoked with (payload, principal)  → use-case module
       → use-case → SheetStore (Sheets) / DrivePhotos (Drive) / SessionService
  ← {ok,data,error,requestId} envelope back through Worker to FE
```

**Key invariant:** the client never supplies role/permission/owner identity. RBAC and ownership
are resolved server-side from the session (`SessionService.ROLE_PERMISSIONS` + `OPERATION_PERMISSIONS`).

## 9. Quick "where do I change X"

- **Add/modify an API op:** use-case module (§3) + all gates (§7).
- **Change a permission:** `OperationController.OPERATION_PERMISSIONS` + `SessionService.ROLE_PERMISSIONS` + `api-permissions.v1.json` + RBAC matrix.
- **Change health/version label:** `SystemGroup.js` `backendVersion` (guard: `contract.test.mjs` asserts === package.json).
- **Sheets write/read behavior:** `SheetStore.js` (text coercion, bounded snapshot — no joins).
- **FE page/API call:** `features/<area>` + `application/<area>` + `infrastructure/<area>` adapter.
- **Worker allowlist/origin:** `tools/p6vc-api-test-console/worker.mjs`.
