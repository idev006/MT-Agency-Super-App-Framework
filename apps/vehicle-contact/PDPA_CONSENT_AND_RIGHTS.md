## 2. SOP คำขอใช้สิทธิของเจ้าของข้อมูล
รับคำร้องผ่าน [ ] → ตรวจยืนยันตัวตนอย่างได้สัดส่วน → ลงทะเบียนคำขอและวันได้รับ → ส่ง DPO/เจ้าหน้าที่ตรวจฐาน/ข้อยกเว้น → ดำเนินการภายในกรอบกฎหมายที่ใช้บังคับ (ไม่แต่ง SLA) → แจ้งผล/เหตุปฏิเสธ → เก็บบันทึกหลักฐานเท่าที่จำเป็น
คำขอครอบคลุมขอเข้าถึง แก้ไข ลบ คัดค้าน จำกัดการประมวลผล ถอนความยินยอม (เฉพาะฐาน consent) และสิทธิอื่นตามเงื่อนไขกฎหมาย

## 3. SOP เหตุละเมิดข้อมูล
พบเหตุ → กักกันความเสียหาย/ปิดสิทธิ์ที่เสี่ยง → บันทึกเวลาและประเภทข้อมูล → แจ้งเจ้าของระบบและ DPO ทันที → ประเมินความเสี่ยงต่อสิทธิและเสรีภาพ → พิจารณาการแจ้ง สคส. ตามเกณฑ์และกรอบ 72 ชั่วโมงตามกฎหมายที่ใช้บังคับ พร้อมข้อยกเว้น/เหตุล่าช้า → แจ้งเจ้าของข้อมูลกรณีมีความเสี่ยงสูงตามเกณฑ์ → แก้ไขและทบทวน
เอกสารเหตุ: [เวลา ทะเบียนเหตุ ระบบ ข้อมูลที่เกี่ยวข้อง ขอบเขต การแก้ไข ผู้วินิจฉัย การแจ้ง/เหตุไม่แจ้ง บทเรียน]

## 4. ข้อกำหนดระบบ
บังคับ login และตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์, QR ไม่ฝังข้อมูลติดต่อ, ป้องกันค้นข้อมูลจำนวนมาก, บันทึก log เท่าที่จำเป็น, ทบทวนสิทธิ์, แยกสิทธิ์ผู้ดูข้อมูลกับผู้แก้ไข, มีการสำรองและลบตามกำหนด
