## ห้าม Go-live สำหรับข้อมูลจริงหากช่องเหล่านี้ยังไม่ผ่าน
- [ ] ผู้ควบคุมข้อมูลและหน่วยเจ้าภาพอนุมัติ
- [ ] ตรวจ PDPA 2562, ฉบับแก้ไขและประกาศที่เกี่ยวข้อง ณ วันเริ่มจริง
- [ ] ฐานกฎหมายรายกิจกรรมมีข้อกฎหมาย/คำสั่งอำนาจรองรับ
- [ ] ROPA ลงรายการครบและรับรอง
- [ ] Privacy Notice บุคลากร/ผู้มาติดต่อเติมข้อมูลจริงและติดประกาศ
- [ ] Consent จัดทำเฉพาะกิจกรรมที่จำเป็น และช่องทางถอนพร้อมใช้งาน
- [ ] Retention schedule เป็นจำนวนวัน/เงื่อนไขที่มีผู้อนุมัติ
- [ ] ผู้รับบริการ cloud และการโอนต่างประเทศได้รับการประเมิน
- [ ] ทดสอบรั่วข้อมูล ไม่มี anonymous access การค้นจำนวนมากและ direct API
- [ ] มี SOP สิทธิของเจ้าของข้อมูลและการแจ้งเหตุละเมิด
- [ ] ฝ่ายกฎหมายและ DPO ลงนามทวนสอบผล
